## Definisi Git
Git adalah version control system yang melacak siapa, kapan, dan apa saja yg sudah dirubah dalam suatu file.
Git diciptakan oleh Linus Torvalds pada tahun 2005. Alat ini dirancang untuk mencatat setiap perubahan yang terjadi pada file.

---

## Git Workflow
1. Working directory/tree adalah salinan dari satu versi proyek yang sedang kamu kerjakan. File-file di dalamnya diambil dari database yang tersimpan di direktori Git, kemudian ditempatkan di komputer agar dapat digunakan atau dimodifikasi.
2. Git directory adalah tempat Git menyimpan metadata dan object database dari sebuah proyek. Bagian ini merupakan komponen terpenting dalam Git karena berisi seluruh informasi yang dibutuhkan Git untuk mengelola proyek. Ketika kamu melakukan clone repository dari komputer lain, bagian inilah yang akan disalin.
3. Staging area adalah file yang umumnya berada dalam direktori Git dan berfungsi untuk menyimpan informasi mengenai perubahan apa saja yang akan dimasukkan ke dalam commit berikutnya. Dalam istilah teknis Git, staging area disebut sebagai index.

## Essential Git Command
1. git init
2. git add .
3. git commit -m 'message'
4. git remote add <name> <url>
5. git push origin main
6. git pull origin main
